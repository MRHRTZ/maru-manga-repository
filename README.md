# Maru Manga Source Repository

`metadata.json` is the validated source catalog consumed by MaruManga Downloader. Root catalog versions and per-source versions use `MAJOR.MINOR.PATCH` semantic versions. Bump the root version when catalog entries or metadata change; bump a source version when that adapter's behavior or configuration changes. Integer source versions remain accepted only for older repositories during migration.

Catalog `1.23.1` includes reviewed bundled adapters for Komiku `3.0.0`, MangaRock `2.0.0`, MangaMost `3.0.0`, WEBTOON English `1.1.0`, WEBTOON Indonesia `1.0.0`, Mangago `1.1.0`, and WestManga `1.0.0`. Catalog metadata contains configuration only. The plugin never downloads or executes Lua from a repository; source files here mirror the reviewed bundled implementations.

Each source entry and its per-source `metadata.json` includes an `icon_url` pointing at the source website's 64-pixel favicon. The plugin bundles these small icons for immediate display and uses metadata icon URLs for other compatible sources. Icons remain the property of their respective source sites.

- **MangaMost** is the public JSON API used by Android package `baca.read.komik.manga`. It is identified and tested separately from the Mangago website.
- **Mangago** is the Mangago website and is marked NSFW. This workspace gets HTTP 503 from `www.mangago.me` even when TLS validation is bypassed, while `www.mangago.zone` serves Mangago search, work, and chapter pages. The plugin uses that reachable origin and skips certificate validation only for this exact source, while retaining HTTPS and exact host allowlists. Live search, title, chapter HTML, AES-encrypted image URL manifest decoding and all six page-image downloads were checked. The downloaded pages are valid JPEGs; representative tall pages were visually checked as continuous images without shuffled tiles.
- **WEBTOON** scrapes server-rendered public English and Indonesian search, ranking, title, episode-list and viewer pages. English uses source ID `webtoon`; Indonesian uses `webtoon_id`. It does not execute site JavaScript.
- **WestManga** uses its public JSON catalog/chapter endpoint and server-rendered Indonesian title/chapter pages at `www.westmanga.shop`. Search, ranking, latest updates and 60-chapter pagination are supported; chapter images load through the allowlisted WestManga image proxy.
- **MangaRock** supports public search, Popular Today, latest updates, metadata, English chapter batches and page images. Its observed page-image host is `llma.zogana.lol`; changed image hosts require a reviewed catalog update.
