This native Lua adapter selectively ports public source behavior from the Komiku extension in [Keiyoushi extensions-source](https://github.com/keiyoushi/extensions-source/tree/main/src/id/komiku), licensed under Apache License 2.0. The reference implementation is at `src/eu/kanade/tachiyomi/extension/id/komiku/Komiku.kt`. The bundled Apache-2.0 license is at the plugin's `third_party/keiyoushi/LICENSE`.

The port uses public HTML/API endpoints and does not execute JavaScript or bypass login, paywalls, DRM, or access restrictions. Respect Komiku's terms, rate limits, and applicable law.
